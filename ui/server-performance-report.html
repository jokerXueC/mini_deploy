CPU 为整体占用率，100% 表示所有逻辑处理器繁忙。数据缺失不补零；断电或强制终止可能丢失尚未保存的最近 30 秒。每次 Agent 启动独立记录，不覆盖重启前同一区间的采样。时钟变化会影响时间排序。

网络为非回环接口之和，可能含虚拟接口；磁盘速率为已识别设备之和。延迟按采样 IOPS 加权，忙碌率取当时最忙设备，不等于所有磁盘同时繁忙。负载超过逻辑核数可作为排查依据，单次峰值不代表持续故障。
