    连接你的代码仓库
    
              
    
                
              
    
              
    
                
    Compose 项目可自动查找目录和仓库。
    
                
    
                
    
                
    
                
    找不到项目？查看查询指令
                  
    在服务器终端执行。Compose 的 CONFIG FILES 是配置文件路径，代码目录可在它所在目录继续查询。
    
                  
    docker compose ls
    
                  
    进入你原来部署项目的目录，再执行。第一行是 Git 代码目录，第二行是仓库地址；不要分享含密码或 Token 的地址。
    
                  
    git rev-parse --show-toplevel
git remote get-url origin
    
                  
    本机运行的服务可先查服务名称，再查询真实目录和启动方式；将下面的 my-app.service 换成你的服务名称。
    
                  
    systemctl list-units --type=service --state=running --no-pager
systemctl show my-app.service -p WorkingDirectory -p ExecStart
    
                
    
              
    
              
    
              
              
    指定分支 / 自建代码平台
    
              
    仓库地址在哪？私有仓库怎么授权？
    GitHub：仓库首页 → Code；Gitee：仓库首页 → 克隆/下载。复制 HTTPS 或 SSH 地址，例如 https://github.com/your-name/my-app.git。
    私有仓库需要服务器读取权限。HTTPS 使用服务器已有的 Git 凭据；SSH 需在代码平台添加服务器公钥，并确认平台主机指纹。仓库地址中不要填写密码或 Token。
