从你自己的服务器开始。

安装 mini_deploy

准备一台 Linux 主机，具备 root 权限、systemd、Python 3.10+ 与 Git。安装向导默认中文，可选择英文。

git clone https://gitee.com/XC1960/mini_deploy.git mini-deploy-source
cd mini-deploy-source
bash install.sh

在 root 终端执行。Git 需预先安装。

  1. 设置管理员密码

    跟随向导完成安装。Docker、Nginx 按需要选择，域名不是必填项。

  2. 打开服务器面板

    访问 http://服务器IP:6868，放行云安全组的 6868 端口，并限制访问来源。

  3. 按需要接入功能

    先查看本机状态，再配置请求采集、通知、模型或 IP 防护。

当前为预发布项目，Agent 默认以 root 运行。建议先在受控测试服务器验证；传输 SSH 凭据与模型密钥时优先使用 HTTPS 或本地隧道。

开始前，你可能想知道。

需要修改现有业务的部署方式吗？

不需要。mini_deploy 管理已运行的主机与服务，不提供应用构建或 Git 自动部署。请求记录需要接入支持的代理日志或独立请求网关。

是不是必须安装 Docker、购买域名？

都不是必选。主机监控可以独立使用；Docker 功能需要 Docker。面板默认通过服务器 IP 和 6868 端口访问，连接主机的网络必须可达。

AI 会自动操作我的服务器吗？

面板性能与告警诊断只读。SSH 工具遵循所选权限，支持修改前审批或明确授权的临时自动操作。已有文件修改前备份，禁止任意脚本执行与业务文件删除。

安全中心和 SafeLine 有什么区别？

安全中心检查主机与容器配置、记录登录活动，并通过 Fail2ban 管理登录防护。SafeLine 是 Web 应用防火墙（WAF），还提供请求内容检测等能力。mini_deploy 不提供 SQL 注入、XSS 或 DDoS 检测承诺，也不会自动接管业务流量。Docker 与反向代理的封禁效果取决于实际入口和防火墙规则。

数据和模型请求会发到哪里？

监测历史保存在面板服务器。启用 AI 后，问题、所选上下文与工具证据会发送到你配置的模型服务，常见凭据会脱敏。请根据自己的数据要求选择模型与使用范围。
