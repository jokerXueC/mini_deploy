# 远程终端

## AI 对话

正式面板「远程终端」右上方有 **模型设置**，无需先连接 SSH。

1. 选择接口类型：**OpenAI 兼容**，或 **Anthropic / Claude 原生**。
2. 填写服务商的接口地址、模型名称和 API Key。Claude 官方地址为 `https://api.anthropic.com/v1`；OpenAI 兼容服务填写其 Base URL；本机 Ollama 可填 `http://127.0.0.1:11434/v1`。模型名称以账号实际可用的模型为准。
3. 点击「测试连接」，成功后「保存设置」。测试只发送一条连接测试文字，不发送终端内容；测试和分析会按服务商规则消耗额度。
4. 点击「AI 对话」，例如输入「帮我检查容器为什么退出」。连接 SSH 后，AI 可以查日志、搜索文件、排查系统和网络，也能备份后修改配置、校验并启停服务；默认修改前逐次确认。可以继续追问，没有 SSH 时仍可普通对话。
5. 连接 SSH 后，默认附带当前终端最近输出；不需要时取消勾选。发送前可看到模型服务地址。可选「跟进新输出」在首条提问后每 30 秒检查一次，有新输出才分析；切换连接或离开本页会停止。

设置与分析支持 **HTTPS、本地 SSH 隧道，以及页面确认后的 HTTP**。密钥保存在面板数据目录 `ai/model.json`，Linux 目录权限 700、文件权限 600，不回显给浏览器；留空保留原密钥，更换服务地址或接口类型需重新填写密钥。常见凭据会脱敏，其他敏感内容仍需在发送前核对。

聊天框中选择操作权限：

| 权限 | 行为 |
| --- | --- |
| 仅对话 | 不调用服务器工具，只回答问题 |
| 只读检查 | 自动读取和搜索文件、检查日志、系统、网络、容器与服务，以及校验配置 |
| 修改需确认（默认） | 检查直接执行；文件创建/编辑、容器与服务启停、重启/重载前展示目标、具体变更和影响，逐次确认 |
| 自动操作 | 勾选授权后，在受支持的工具范围内直接操作，不再逐次询问 |
| 通用命令 · 逐条确认 | 单独授权后可提交 Shell 命令、容器内查询等；每条命令均需确认 |

默认无需额外授权即可检查或提出待审批操作；实际修改必须同意该次操作。「自动操作」需单独勾选授权，仅对当前登录、SSH 连接和模型配置生效，最多 30 分钟；可随时改回其他模式撤销，断开连接、退出登录或更换模型也会撤销。容器修改使用完整 ID，避免误操作同名的新容器。操作按当前 SSH 账号权限执行，不自动提权。上述受控模式保留禁止删除的边界，不开放任意 Shell/脚本、文件删除、Docker 清理或软件卸载。

需要执行容器内的 PostgreSQL 查询等操作时，选择「通用命令 · 逐条确认」并明确授权。AI 优先使用受控工具，遇到未适配的操作可提交完整命令和用途；核对目标服务器和命令后确认执行。该授权同样最多 30 分钟，现有自动操作授权不会升级。**任意命令可能修改或删除数据，无法保证禁止删除，也不自动备份或回滚**；需要严格保留文件时保持受控模式。模型不能自行开启此权限，后台跟进仍只读。

配置修改先展示服务器、真实文件差异和影响，再按当前权限执行。已有文件会保留原文备份，并回读校验备份和写入结果；已知实际 Nginx/Caddy 主配置时还可校验语法。校验失败会阻止本轮后续修改和重载。文件写入成功不代表业务已经生效。

展开执行记录可点击「恢复备份」，历史记录中也能恢复。恢复先预览差异、备份当前版本，并核对当前文件和原备份的摘要；文件被他人修改时拒绝覆盖。仅操作原服务器，不删除备份或新创建的文件，不自动重载服务。任务可停止，但已经提交的远端操作仍需核对状态。

操作权限旁的体检按钮检查当前 SSH 服务器的资源、容器、服务和端口，并提示可识别的磁盘/内存不足、容器或服务异常。不需要配置模型，不修改服务器；结果保存到对话历史，可继续让 AI 分析。终端与 AI 之间可拖动调宽，双击恢复默认；标题栏放大按钮可将对话居中显示，再点一次或按 Esc 恢复侧栏，保留草稿和执行状态。回复支持表格、粗体、列表和代码块。

例如问「默认路径下有哪些文件」，AI 会直接列出 SSH 登录目录（含隐藏文件）再分析，也可指定「查看 /opt 下的文件」。仅列出文件信息，不读取内容、不递归。检查使用独立通道，不继承终端中手动执行的 `cd`；结果会显示实际目录。

要分析日志，直接问「读取 /var/log/nginx/error.log，检查最近的异常」。AI 会读取指定文件的末尾 100 行，也可要求查看开头；每次最多 200 行、8 KiB，较大文件仅分析该片段。文件不存在或账号无权限会明确报错，不自动提权，不修改或删除文件。常见凭据会在发给模型和保存历史前脱敏。

还可以直接问：

- 「在 /etc/nginx 中找配置文件，查找包含 proxy_pass 的位置。」
- 「检查进程、网络路由和 Docker 即时资源占用，分析连接失败的原因。」
- 「检查 https://example.com/health 是否能访问。」
- 「把 /etc/nginx/conf.d/app.conf 中这一处端口从 8080 改为 8081，校验通过后重载 nginx。」

文件操作通过 SSH 的 SFTP 通道执行，不需要目标服务器安装 Python 或额外 Agent；须启用 SFTP。支持分页读取大日志，搜索有范围和数量限制。编辑只支持不超过 1 MiB 的 UTF-8 普通文件；先检查 SHA-256，审批后仍会核对版本，原文备份保存在同目录的 `.mini-deploy-backup.*` 文件。变更期间若检测到文件已改变、目标是符号链接或权限不足，会停止操作。原子替换须服务器支持 OpenSSH SFTP 扩展；失败时保留备份和候选文件供核对，不自动清理。不编辑私钥、密码或认证策略，也不会把脱敏占位符写回配置。

已有文件的账号、属组和普通权限会保留；扩展属性和 ACL 不由 SFTP 复制。有这些特殊要求的文件需使用原管理方式。Docker 单文件挂载可能在宿主文件替换后继续使用旧文件，需要确认容器中实际配置已更新；AI 不会把宿主写入成功当成业务生效。

工具结果和选中的最近输出会脱敏后发给模型服务，不会扫描全服务器文件。取消附带只停止发送新的终端输出，工具结果和之前的问答仍会参与对话；点击「新建对话」可重新开始。

对话自动保存到数据目录 `ai/history.sqlite3`，点击 AI 助手右上角「对话历史」查看。刷新、退出登录、升级和服务重启不会清空历史；该面板使用单一管理员账号，历史仅向已登录且已获准使用终端功能的管理员开放。可继续历史对话，服务器对话需先连接同一地址、端口和账号；历史不会恢复 SSH 连接或操作授权。长记录分页查看，只给模型发送有界的近期上下文。保存的问答、附带输出和工具结果会做常见凭据脱敏，数据库目录权限 700、文件 600。

执行过程在聊天中展示，结果可展开并保存到历史。审批等待最多 2 分钟；受控 SSH 操作默认等待 20 秒，通用命令默认 60 秒，可指定最多 600 秒。通用命令输出最多保留 64 KiB，截断后仍继续读取并等待退出码；可让 AI 使用更精确的查询减少输出。模型总等待时间和工具轮数不设固定上限，服务商限制仍适用。点击「停止任务」会停止后续操作、取消待审批操作并关闭当前工具通道；已提交的远端修改可能仍在执行，应核对状态。模型请求也不保证能在服务商一侧取消。跟进新输出始终只允许只读检查。

工具检查面向 Linux 服务器，Docker 和 systemd 功能取决于目标服务器是否安装及账号权限。模型需支持工具调用；服务拒绝工具请求时会提示切换「仅对话」。建议命令仍可复制或填入终端，是否按回车由你决定。审计只记录授权、审批和工具名称、结果状态，不记录日志内容或凭据。

## 在自己的电脑测试

在项目目录执行（Windows 也支持，不需要本机安装 SSH 服务）：

```powershell
python -m pip install -r requirements-ssh.txt
python scripts/local_ssh.py
```

打开 `http://127.0.0.1:60678/ui?view=terminal`，使用命令输出的密码文件中的**本地面板密码**登录，然后填写目标服务器 IP、SSH 端口、账号及密码或私钥。该入口连接真实服务器，仅监听本机；其他监控与服务器管理功能不在这个测试入口运行。

本地面板密码、地址及指纹保存在 Windows 用户的 `%LOCALAPPDATA%/mini_deploy/local-ssh`（其他系统为 `~/.local/share/mini_deploy/local-ssh`），重启后保留；目标 SSH 密码与私钥不保存。端口被占用时可用 `python scripts/local_ssh.py --port 60679`。按 Ctrl+C 停止。

点「新建连接」会断开当前终端，再清空连接表单；保存的地址不受影响。

## 连接服务器

1. 打开面板，登录后进入「远程终端」。通过 HTTP 访问时，阅读上方提示并勾选确认，点击「允许本次登录使用 HTTP」，即可填写连接信息并配置模型；HTTPS 或本地隧道无需这一步。
2. 填写服务器 IP 或主机名，例如 `192.168.1.20`；SSH 端口默认 `22`。用户名通常是 `root`、`ubuntu` 或 `debian`，以服务器实际账号为准。
3. 选择密码或私钥。私钥支持 OpenSSH/PEM 格式的 Ed25519、RSA、ECDSA；加密私钥还要填写口令。支持文件上传或粘贴内容。
4. 点击「连接服务器」。第一次连接会显示主机指纹；通过云厂商控制台或已有可信 SSH 会话，在目标服务器执行页面提供的 `ssh-keygen` 指令核对，再勾选确认。
5. 进入终端后可以操作命令、Ctrl+C、方向键、交互程序。断开后重新连接需重新输入凭据。保存地址仅保存名称、IP、端口和用户名。

连接路径是 **你的浏览器 → 面板服务器 → SSH 目标服务器**。目标服务器不用安装 mini_deploy；账号权限、SSH 服务、防火墙和网络以目标服务器实际设置为准。本版本不提供跳板机、SSH Agent、硬件密钥或交互式 MFA。

HTTP 确认仅对当前登录及面板地址生效，刷新后保留，退出并重新登录后需再次确认。浏览器到面板的密码、私钥、API Key 和终端内容会以明文传输，面板到目标服务器的 SSH 仍然加密；使用公网网络时建议 HTTPS 或以下本地隧道。模型服务端的远程接口仍须填写 HTTPS 地址。

## 没有域名也能用

在自己的电脑执行，把 `服务器IP` 换成**面板所在服务器**地址，端口不同则修改 `22`：

```bash
ssh -p 22 -N -L 16868:127.0.0.1:6868 root@服务器IP
```

保持命令运行，打开 `http://127.0.0.1:16868/ui?view=terminal` 登录。浏览器到本地地址的 HTTP 不经过公网，电脑到面板服务器的传输走加密 SSH 隧道。

已有 HTTPS 反向代理时，转发原始 `Host` 和 `X-Forwarded-Proto`；代理需连接 Agent 的 `127.0.0.1:6868`。确认代理会覆盖客户端提供的转发头后，在 `/etc/mini-deploy-agent.env` 设置 `DEPLOY_TRUST_LOOPBACK_PROXY_HEADERS=true` 并重启 Agent。安装器管理的本机 Nginx 入口会设置此选项。不信任来自公网连接的 HTTPS 声明，Docker 网桥代理暂不在此信任范围。

代理读取超时需至少 30 秒，连接认证时建议 60 秒。终端输出走持续 HTTP 流，服务端会关闭 Nginx 的响应缓冲；自定义代理也应避免缓冲 `/ssh/stream`，否则输出可能积攒后才一起显示。不需要额外开放 WebSocket 端口。

终端支持远端程序的 ANSI 彩色输出，深浅主题各有完整配色。目录、警告等颜色由远端 Shell 或程序决定；纯文本仍按原样显示。输入没有本地回显，会等待远端确认显示，因此电脑到面板、面板到 SSH 服务器的网络延迟仍会影响手感。

## 会话与安全

- 凭据只用于当前认证，不落盘、不进入连接列表或审计日志；终端输入输出不写入面板日志。远程服务器自身可能有登录/命令审计。
- 主机指纹保存到面板数据目录的 `ssh/connections.json`（目录 700、文件 600），服务器指纹改变时必须重新核对。连接时再次验证指纹，验证失败不会发送凭据。
- 每个面板登录最多 4 个会话，整个 Agent 最多 12 个。连接尝试有限流，验证结果 2 分钟内有效。
- SSH 空闲或页面离线超过 24 小时、登录过期或服务关闭时断开。默认面板登录有效期为 24 小时；升级会将旧版默认的 8 小时改为 24 小时，自定义期限保留。升级后重新登录才会取得新的有效期。浏览器正常关闭页面仍会主动请求断开；远端 SSH 服务自身的超时策略也可能关闭连接。
- 原面板的旧登录仍能使用其他页面；SSH 要求退出后重新登录以获取带随机标识的独立登录会话。
- 终端输出采用有界缓冲：服务端每会话最多保留 256 KB 待读取数据，浏览器保留 3000 行滚动记录；输出过快时提示跳过早期内容，避免持续占满内存。
- 输入按顺序发送；发送失败不会自动重发命令。含换行的粘贴需要确认，可能立即执行命令。
- 操作审计记录连接、断开及地址保存/移除，不记录命令内容。移除连接地址不操作远程文件或服务，保留主机指纹。

终端命令使用目标账号权限执行；面板不会自动运行运维或清理命令。关闭 SSH 会话不保证结束已在远端后台运行的任务，执行命令后需自行核对远端状态。

## 排查

组件未安装：Debian/Ubuntu 执行 `apt-get update && apt-get install -y python3-paramiko`，然后 `systemctl restart mini-deploy-agent`。其他发行版用对应包管理器。自定义 Python 环境需在该运行环境安装 `requirements-ssh.txt`，不要强制向受系统管理的 Python 执行 pip 安装。

连接失败：核对目标 IP、端口、SSH 服务、安全组；检查**面板服务器**是否能连到目标。认证失败：核对账号与凭据，服务器可能禁止 root 或密码登录。指纹变化：先确认是否重装/更换服务器，不要直接接受未知指纹。

本地测试已覆盖真实 SSH 握手、密码/加密私钥登录和浏览器交互；Debian 上真实 OpenSSH、长时运行和公网代理仍需实机验收。
