# 模块检查记录

检查日期：2026-10-22。范围为 mini_deploy 自有业务代码、前后端接口、安装更新清单和自动化测试。重点检查安全中心，同时核对其他模块的权限、数据保留、异常处理和联动行为。本轮改动仅在本地，未操作线上服务器、未推送。

## 已修复的问题

| 问题 | 影响 | 本轮处理 |
| --- | --- | --- |
| SSH / Fail2ban journal 读取最新 N 条后推进时间位置 | 日志积压时，中间尚未采集的记录可能被跳过 | 改为从最早待处理条目分批读取，持久保存 journal 游标；游标失效时按时间回退并标记可能有空档 |
| 文件日志来源识别遗漏 `sshd-session` | 部分新版 OpenSSH 的登录事件无法自动发现 | 扩展识别，保留原 `sshd` 支持 |
| Fail2ban 数据不完整仍被当作恢复证据 | 采集达到上限、首次截尾或轮转时，封禁突增告警可能错误解除 | 数据不完整时保留告警并标记未知，不确认恢复 |
| 安全中心读取失败仍显示旧核验状态 | 用户可能把旧的“已读取”当作当前状态 | 明确提示读取失败、保留记录、标记待核实，暂时禁用修改操作；失败的翻页或筛选恢复到上次成功状态 |
| 防护任务查询失败后停止跟踪 | 后台操作可能继续，但界面提前恢复按钮 | 自动重试任务查询；提交响应丢失时也先查询结果，不重复 POST |
| 托管 Fail2ban 配置损坏或操作参数类型异常 | 接口可能抛出未处理异常，浏览器只显示网络错误 | 限制配置读取大小，返回明确 JSON 错误，保留配置；拒绝畸形操作参数 |
| 证书、Nginx 配置和网关日志升级失败时直接写回旧文件 | 可能覆盖校验或重载期间的外部修改 | 写入、回退前复核内容；发现外部修改时停止覆盖，保留证书备份或网关事务记录并提示处理 |
| 性能采样过期后未更新告警采集状态 | 告警本身标记过期，但采集覆盖状态可能缺失或仍为旧状态 | 同步标记采集未知，清理内存增长计算基线，新采样后恢复 |
| CI 的检查范围落后于模块增长 | 部分新 Python 模块未纳入 lint；浏览器测试因缺依赖跳过 | 改为全项目 Ruff 检查，新增安装 Chromium 的浏览器测试任务；更新过时的启动线程和 AI 下拉菜单测试 |

安全事件分页上限已核实：统一事件列表允许到第 4000 页，能够覆盖当前两类各 20000 条的保留量，不需要修改分页上限。

## 2026-10-23 可靠性修复（本地）

| 问题 | 本次处理 |
| --- | --- |
| 安装器和面板更新的程序清单不一致 | 统一读取 `release.json`，补齐登录防护等模块；更新兼容约定提升到 3。旧版面板拒绝跨约定在线更新，需用新版源码的 `install.sh` 升级一次 |
| 高频请求超过单批上限后遗漏，明细淘汰连带丢失统计 | 按顺序分批续读，持久化秒内位置与校验锚点；事务同步提交游标、明细、独立分钟汇总；已有记录补建汇总，导出同时提供保留统计 |
| 日常操作挤掉异常历史 | 异常与恢复事件、日常事件各保留最多 1000 条，继续受 30 天保留期限制；界面每页仍为 5 条 |
| 慢请求占用 HTTP 工作线程 | 总连接数 128、每来源 IP 32；请求头绝对期限 10 秒及 64 KiB，上传读取期限 120 秒，阻塞写入期限 30 秒；不限制 AI、SSH、SSE 的总响应时长 |
| Docker 慢采样阻塞状态接口，前端读取无法结束 | Docker 查询与历史写盘移到后台，读接口只返回快照；超过 65 秒标注过期，界面显示容器自己的采样时间；普通 JSON 读取包含响应体的 20 秒超时，不自动重试修改操作 |
| 防护启用后不更新端口、入口和白名单 | 定期重查并更新自有规则；外部修改保留并提示；未变化的配置不重复重载；关闭只恢复仍与面板应用值一致的登录防护字段 |
| 接口异常判断过于单一 | 可选 GET/HEAD/POST、请求头、状态码和 JSON/文本校验；凭据不回显，跨来源修改不沿用凭据；基于完整五分钟汇总识别持续 5xx、超时及 P95 偏高，缺失数据不判断为恢复 |

安全中心目前是基础防护与风险检查：读取常见配置和登录活动、管理 Fail2ban、提示容器权限与端口风险。它不是完整 WAF 或入侵检测系统。高流量请求采集仍有批量和保留预算，达到上限会标记数据可能不完整；不会把未知数据当作零请求或安全结论。
