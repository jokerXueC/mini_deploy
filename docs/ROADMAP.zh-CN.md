# mini_deploy 路线图

项目名称保持 mini_deploy，方向调整为服务器运维与请求监控面板。不再建设通用部署平台，旧路线中的仓库适配、部署模板、脚本向导、WebHook 发布、部署队列恢复和部署策略不再推进。

本页区分已完成实现和后续工作，不承诺发布日期。

## 保留范围

- CPU、内存、磁盘、网络监控。
- 通用网站监测：输入网址，自动检查可用性、响应耗时和线上 TLS 证书，无需代理适配。
- 统一告警：持续异常判定、恢复通知、重复提醒间隔、临时静音；提醒和规则重启后保留。
- Docker 容器状态、日志与管理，镜像列表、搜索、拉取和非强制删除。
- 主机 Docker 镜像加速：读取现有配置、增删修改、备份校验、热加载/受限重启、生效核对和失败恢复。
- 网站与证书自动发现：统一展示本机、Docker 配置和常见证书目录，无需预选代理类型或填写路径。支持 Nginx/Caddy 配置，保留原服务自动续签；符合条件的手动证书支持备份后替换及失败恢复。
- 本机/Docker 证书统一管理，已有托管证书直接从扫描结果替换；内部入口和默认站点默认折叠，移除重复的站点登记和手动接入表单。
- Nginx/Caddy 请求日志采集、请求统计与独立 Docker 网关。
- 管理员认证、Session、CSRF、审计、安装诊断及配置备份。
- 远程 SSH 终端：密码/私钥登录、主机指纹核对、连接地址管理及有界会话生命周期。
- 正式终端 AI Agent：OpenAI 兼容及 Claude 原生工具调用、连续追问、独立 SSH 检查通道、只读/逐次审批/自动操作权限、连接与模型绑定授权、执行进度和取消；不开放任意命令或文件删除，无 SSH 也能普通对话。

继续保持轻量、可自托管；主体使用 Python 标准库，请求历史使用内置 SQLite，SSH 使用 Paramiko。监控与业务发布解耦，读取状态不应自动重启业务。

## 已完成

- 安全中心：风险概览、SSH 登录活动、主机/Docker 只读检查、常见配置摘要变化与统一事件时间线；Fail2ban 面板/SSH 防护、白名单和封禁管理默认收起。集中登录失败与封禁汇总沿用现有告警。只读检查不证明公网可达或已经入侵，实际拦截仍待 Linux 验收。

- 面板维护页面：官方仓库版本检查、完整备份与校验、程序快照恢复；独立 systemd 维护任务在面板重启后继续执行，健康检查失败时尝试恢复旧程序。保留现有数据、配置与业务文件，不删除备份；跨兼容约定更新转回安装器。自动化隔离验证已加入，Linux 实机验收待完成。
- 增加 Swap、根分区 inode、磁盘读写/IOPS/等待耗时/I/O wait；容器 CPU/内存每 30 秒持久记录，最多 7 天或 20 万条。请求叶级汇总增加按完整所选时段计算的 P95/P99，原代理来源注明为当前样本分位数，不合并子级分位数。

- 本机只读排查窗口：进程占用排序、监听端口归属、可靠识别的进程/服务/容器日志关联。自动发现常见日志来源，提供有界读取、时间/级别/关键字筛选、暂停刷新和下载。异常详情关联已保存的证据、同次异常记录和保留资源采样；AI 分析先准备草稿，不自动提交或执行操作。Linux 命令与真实日志格式仍需实机验收。

- 移除部署页面、队列、脚本执行和仓库识别适配器；旧部署 API（含手动部署、回滚及 WebHook）返回 HTTP `410 Gone`。
- 独立站点通过 `/sites`、`/sites/save`、`/sites/delete` 增查改删。填写名称、域名和端口，后端地址在 Nginx 入口设置；健康检查可选，高级 key 留空自动生成。
- 站点写入 `sites.json`，旧 `projects.json` 只读提取站点。监控写入 `monitoring-state.json`，原 `state.json` 保留且不加载队列，启动和重启均不恢复旧部署任务。
- 升级保留旧业务文件、配置、脚本、服务、容器及持久数据，不因移除部署而清理或重建资源。
- Docker 可选安装用于容器管理、Docker Nginx 和请求网关：默认询问且默认回答“否”，无终端时跳过，不自动选择“是”；不需要 Compose 或 PyYAML。
- 异常中心以当前故障为主，网站检查与提醒规则默认折叠；严重度、来源与状态筛选，事件历史和面板操作分开显示。已知晓状态持久保存，仍异常的故障不会被隐藏或清除，新一轮故障重新提醒。
- Docker 状态检查补充退出码、OOM、健康检查退出码及近 5 分钟新增重启；按 Compose 服务/副本关联重建。事件流记录容器生命周期，断线重连与有界去重；定时检查核对状态，未知样本不触发恢复。事件历史最多保留 30 天或 1000 条。
- SSH 终端独立页面，xterm.js 随项目提供；HTTP 支持页面显式确认后使用，确认绑定当前登录和访问地址，退出重登需重新确认；HTTPS/本地隧道无需确认。密码/私钥不落盘。支持指纹首次信任及变化确认、尺寸同步、顺序输入、限流和断线清理；真实 OpenSSH/Linux 长时验收待完成。

验证记录：本轮全量自动化测试 **562 通过、19 跳过**（缺少 Linux/Docker 等环境），JavaScript 测试 **34 通过**；网站监测、证书列表及镜像加速设置已通过桌面/手机浏览器测试。Docker 配置写入和恢复使用隔离测试，**Linux 实机热加载/重启验收尚未执行**。

## 后续工作

安全中心后续：面板两步验证、独立会话查看/撤销和高权限操作拆分；网站限速及访问控制需明确流量入口，完整 WAF 应单独评估成熟引擎。这些能力尚未实现，不作为当前防护承诺。

资源告警扩展为可调阈值与稳定恢复确认，消费现有每秒样本，关联保存的进程现场和附近容器事件；支持重启后读取持久化性能记录。Prometheus `/metrics` 只读缓存接口及网页密钥管理、采集配置下载已加入，外部采集默认关闭，独立只读密钥与管理登录隔离。Linux 长时采集及真实 Prometheus 抓取仍待实机验收，不自动部署外部监控组件。

性能历史新增进程现场：独立后台读取 Linux /proc 的 CPU/RSS/I/O 差值，每 30 秒保留高压力现场，记录进程身份、状态及服务/容器归属。报告支持时间点定位、展开明细和完整现场 CSV 导出；不采集命令参数或环境变量。短暂进程与采样间尖峰无法保证捕获，排名只作为排查线索。

服务器性能持续采集与报告已加入：每秒采样，后台每 30 秒保存平均值和峰值，默认展示最近 24 小时并支持 1 小时/7 天。独立 SQLite 保存历史，重启保留，网页关闭也继续采样。报告包含覆盖率、缺失提示、CPU/内存/网络/磁盘/Swap/负载/I/O 曲线、统计明细与 CSV，使用独立模拟数据验证本地桌面/手机体验；Linux 长时间实机验收仍待完成。

请求记录已加入全量历史导出、CSV 明细与地址/时间统计、离线图表报告和网页预览。导出使用固定快照，不受页面分页及明细样本限制；原代理日志仅导出近期样本并标注范围。凭据字段不导出，CSV 防公式注入，离线报告不访问外部服务。

SSH 文件管理已实现 SFTP 浏览、文本差异预览与备份保存、新建文件夹、分块上传下载和取消传输。没有删除、移动或 chmod 接口；沿用登录、来源校验、CSRF、会话归属与 HTTP 访问确认。真实本地 SSH/SFTP 和桌面/手机浏览器已覆盖，Linux OpenSSH 实机验收仍待完成。

自动发现及证书替换已加入解析、隔离回退和浏览器测试；本机与 Docker 的实际重载仍需 Linux 实机验收。扫描不会遍历整盘，不保证发现非常规路径、动态生成或非受支持代理的站点。

## 升级约束

停止部署触发不等于停止业务。转型不得删除或重写旧业务文件、配置、脚本，不停止或重建已有服务和容器，不删除数据库或 Docker Volume。

升级前已运行的旧部署进程需要先由维护者确认结束；不能用重启旧 Agent 来假定它不会继续执行任务。

已有域名、上游、证书和托管标识继续保留。冲突或无法识别的外部配置不得自动覆盖。
