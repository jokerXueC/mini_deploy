# 远程终端与 AI 诊断预览

安装更新后，打开面板的 `/ui/previews/ssh-ai/index.html`。也可直接在浏览器打开仓库的 `ui/previews/ssh-ai/index.html`。预览使用示例日志、模拟分析和模拟命令，不连接 SSH 服务器或模型服务，也不保存 API Key。

包含深浅主题、诊断区折叠、选中输出分析、分析范围、模型设置，以及只读检查和网络调整的命令确认。移动端使用底部抽屉。

`ui/previews/ssh-ai/icons/` 来自 lucide-static 0.468.0（ISC），完整授权见该目录的 `LICENSE`。终端使用项目已包含的 xterm.js 与 Fit Addon。
